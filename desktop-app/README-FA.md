# FoxyVPN Desktop — نسخهٔ ویندوز

نسخهٔ دسکتاپِ FoxyVPN؛ از صفر بازنویسی‌شده با همان مکانیزم اپ اندروید:
**کلید را وارد می‌کنید، دکمه را می‌زنید، وصل می‌شود.** بدون ایمیل و رمز، بدون پنل، بدون پیکربندی دستی.

## ویژگی‌ها

- **پنجرهٔ کوچک عمودی** با ظاهر موبایلی (دکمهٔ گرد اتصال، کارت سرور، آمار زنده، نوار پایین)
- **فعال‌سازی با کلید** — همان کلیدهای FV1 سازندهٔ کلید (FoxyKeygen) که برای اپ اندروید می‌سازید
- **کد ملی کلید** — هر کلید بعد از اولین فعال‌سازی یک کد ۱۰ رقمی می‌گیرد؛ دفعات بعد فقط همان کد را وارد کنید
- **پروکسی سیستمی خودکار** — با اتصال، ترافیک ویندوز خودکار از تونل می‌رود و با قطع، به حالت قبل برمی‌گردد
- **گزارش مصرف زنده** — مصرف به همان مخزن Gist گزارش می‌شود تا در کلیدساز دیده شود
- **ابطال و شارژ ماهانه** — دقیقاً با قواعد امن اپ اندروید (فقط فلگ صریحِ باطل، ریست ماهانهٔ خودکار)
- بدون کنسول، بدون وابستگی DLL؛ یک فایل exe

## نصب

1. `FoxyVPN-Desktop.exe` را دانلود و اجرا کنید (نیازی به نصب ندارد).
2. اگر ویندوز SmartScreen هشدار داد: **More info → Run anyway**.
3. در اولین اجرا کلید خود را وارد کنید و «فعال‌سازی و ورود» را بزنید.

> نیازمندی: **WebView2 Runtime** (روی ویندوز ۱۱ و اکثر ویندوزهای ۱۰ از قبل نصب است).
> اگر نبود، برنامه خودش صفحهٔ دانلود رسمی مایکروسافت را باز می‌کند؛ بعد از نصب، برنامه را دوباره اجرا کنید.

## استفاده

- **دکمهٔ گرد بزرگ** = اتصال / قطع
- کارت سرور یا تب **سرورها** = انتخاب کشور
- تب **تنظیمات** = اطلاعات کلید، کد ملی، پروکسی سیستمی، اتصال خودکار، لاگ زنده، حذف کلید
- بستن پنجره = خروج کامل و برگرداندن پروکسی سیستم به حالت قبل

## تفاوت با نسخهٔ قبلی ویندوز

| قبلی (v1.1.0) | جدید (Desktop 1.0.0) |
|---|---|
| ورود با ایمیل/رمز موزیلا + کد تأیید | فقط کلید (یا کد ملی) |
| پروکسی سیستمی اختیاری و خاموش به‌صورت پیش‌فرض | خودکار و روشن هنگام اتصال |
| پنل وب/رابط دسکتاپی قدیمی | رابط موبایلی جدید مثل اپ اندروید |
| FoxyVPN.exe | FoxyVPN-Desktop.exe (امضا/هویت جدید؛ تداخل «فایل از قبل وجود دارد» ندارد) |

می‌توانید هر دو نسخه را کنار هم داشته باشید؛ پورت‌ها را خودکار جابه‌جا می‌کند.

## رفع اشکال

- **«کلید واردشده معتبر نیست»** — کلید باید کامل و با `FV1.` شروع شود و از سازندهٔ کلید گرفته شده باشد.
- **«این کلید غیرفعال شده است»** — کلید در مخزن باطل علامت خورده؛ از سازندهٔ کلید کلید جدید بگیرید.
- **«حجم این کلید تمام شده است»** — تا شارژ دوبارهٔ ماهانه صبر کنید (روزهای باقی‌مانده در کارت مصرف نمایش داده می‌شود).
- **وصل شد ولی اینترنت بعضی برنامه‌ها تغییر نکرد** — مسیر عبور، پروکسی سیستمی ویندوز است (مثل حالت مرورگر). برنامه‌هایی که پروکسی سیستم را نادیده می‌گیرند از تنظیمات خودشان `HTTP 127.0.0.1:8080` یا `SOCKS 127.0.0.1:1080` را ست کنند.
- **برنامه باز نمی‌شود** — یک نسخهٔ دیگر در حال اجراست (آیکون کنار ساعت را چک کنید) یا پنجرهٔ WebView2 نصب نیست.
- لاگ کامل: `%APPDATA%\FoxyVPN-Desktop\foxyvpn.log`

## ساخت از سورس

```bash
go-winres make --in winres/winres.json --out rsrc
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -H windowsgui" -o FoxyVPN-Desktop.exe .
```

تست‌ها:

```bash
go test ./...
```
