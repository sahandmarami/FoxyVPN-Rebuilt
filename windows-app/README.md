# FoxyVPN Windows v3 — نسخهٔ دسکتاپِ دقیقاً مثل اپ اندروید

یک فایل `FoxyVPN.exe` تکی، بدون کنسول، با پنجرهٔ عمودی کوچکِ هم‌نسبت گوشی (۳۷۵×۸۰۰، غیرقابل‌تغییر اندازه) که UI آن با WebView2 رندر می‌شود — یعنی شکل‌دهی حروف فارسی، RTL و انیمیشن‌ها با کیفیت واقعی مرورگر، پیکسل‌به‌پیکسل مثل اپ اندروید.

## تفاوت کامل با نسخهٔ قبلی (v2.0.0)

| | v2.0.0 قبلی | v3.0.0 فعلی |
|---|---|---|
| رابط | نقاشی GDI با walk | WebView2 + HTML/CSS/JS جاسازی‌شده در exe |
| ورود | ایمیل/رمز فایرفاکس + کد ۲FA | **کلید FV1** (مثل اندروید) — کپی، چسباندن، «فعال‌سازی و ورود» |
| نسخه‌ها | دوتا exe (console + phone) | **فقط یک exe**، بدون هیچ کنسولی |
| سهمیه | هدرهای X-Quota گاردین | کلید (گیگ پلن) + X-Quota + شمارندهٔ محلی ماندگار |
| پینگ | — | «تست پینگ همه» + پینگ هر شهر در لیست سرورها |

## امکانات (هم‌تراز اپ اندروید)

- صفحهٔ ورود کلید با همان متن‌ها و پیام‌های خطای فارسی اندروید (قالب FV1، امضای Ed25519، انقضا)
- کارت حساب: آواتار حرف اول، «اشتراک X گیگابایتی فعال است ✓»، روزهای باقی‌مانده، «تا …» با تاریخ جلالی، نوار مصرف «X از Y مصرف شده» و «N روز تا شارژ دوبارهٔ حجم»
- دکمهٔ بزرگ پلاگ با هالهٔ رنگی (خاکستری/کهربایی/سبز) و انیمیشن مقیاس
- «وصل است ✓ / در حال اتصال… / قطع است» + تایمر ۰۰:۰۰:۰۰
- قرص «تست پینگ همه» با بهترین نتیجه؛ سه کارت آمار: پینگ / زمان اتصال / مصرف این جلسه
- کارت سرور: پرچم کشور، نام، IP خروجی، «⚡ حجم باقی‌مانده»
- سرورها: فهرست کشور/شهر با پینگ زندهٔ هر شهر و تیک انتخاب
- تنظیمات: پروکسی سیستمی ویندوز (سوییچ واقعی WinINET)، TLS fragmentation، پورت‌های محلی، View logs زنده، Version، Sign out
- سه پالت پاستلی mint/rose/sky — مثل اندروید در هر اجرا تصادفی

## فنی

- **هستهٔ ترافیک**: همان هستهٔ تست‌شدهٔ قبلی (Guardian + Fastly 406 challenge + تونل H2 CONNECT + DoH + TLS split + پروکسی SOCKS5/HTTP محلی) — بدون تغییر رفتار
- **پنجره**: [jchv/go-webview2](https://github.com/jchv/go-webview2) — WebView2 لودر از داخل exe (بدون DLL کنار exe)؛ WebView2 Runtime روی ویندوز ۱۰/۱۱ به‌روز از قبل نصب است؛ اگر نبود پیام فارسی با لینک نصب نمایش داده می‌شود
- **بدون کنسول**: SubSystem=GUI (`-H windowsgui` + مانیفست GUI در winres) — تأییدشده با پارس PE
- **بستن پنجره = خروج تمیز**: تونل بسته و پروکسی سیستمی برگردانده می‌شود (بدون فرآیند پس‌زمینه، بدون تری)
- **single-instance**: اجرای دوباره، پنجرهٔ نسخهٔ در حال اجرا را جلو می‌آورد
- داده‌ها در `%APPDATA%\FoxyVPN` (کلید/توکن‌ها در `tokens.json`، مصرف در `usage.json`، لاگ در `foxyvpn.log`)

## بیلد

```bash
go mod download
go-winres make --in winres/winres.json --out rsrc --arch amd64
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -trimpath -ldflags "-s -w -H windowsgui" -o FoxyVPN.exe .
```

- تست: `go test ./...` (تست E2E هستهٔ تونل/پروکسی روی لینوکس هم اجرا می‌شود + تست کدک کلید FV1)
- فایل آماده در [Releases](../../releases) تگ `windows-v3.0.0`

## کلیدها

کلیدهای FV1 همان کلیدهای اپ اندروید/کلیدساز هستند (هر سه کلید عمومی منتشرشده پذیرفته می‌شود)؛ کلیدِ فعال روی هر پلتفرم مستقل است و مصرف سمت گاردین (X-Quota) بین همه مشترک حساب می‌شود.
